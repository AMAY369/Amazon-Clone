# Amazon Clone

A front-end clone of the Amazon storefront, built with vanilla JavaScript, HTML and CSS. It covers the shopping flow from browsing products through to checkout.

## Features

- Product listing grid with images, ratings and pricing
- Product search
- Add to cart with quantity selection
- Cart page with running totals
- Checkout and order summary flow
- Responsive layout

## Tech Stack

JavaScript, HTML, CSS. No framework and no build step.

## Getting Started

Clone the repository and open `index.html` in a browser:

```sh
git clone https://github.com/AMAY369/Amazon-Clone.git
cd Amazon-Clone
```

For the best result serve it locally rather than opening the file directly, so that relative paths and fetch calls behave normally:

```sh
npx serve .
```

## Notes

This is a front-end project built to practise DOM manipulation, state handling in plain JavaScript and responsive layout. Product data is local and no real payments are processed.
